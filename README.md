# ozashub-loader

Loaders for the Ozashub script. Each one opens the key window, then loads the script from LuaProt once
the key checks out.

## Load it

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ozashub/ozashub-loader/main/loader.lua"))()
```

Developer build:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ozashub/ozashub-loader/main/dev.lua"))()
```

Get a key: https://adrenalin.mykomerza.com/product?id=ozashub
